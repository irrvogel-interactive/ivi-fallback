# Irrvogel switch-on file / Irrvogel-Einschaltdatei

**English.** Irrvogel Interactive's plugins check license keys with a license server. If that
server stops working for good, this repository receives the file `irrvogel-switch-on.json`.
With it, every Irrvogel plugin activates with the buyer's own license key without the license
server, offline and in every version (license terms, section 1; terms of sale, section 3).

- **Is the file here?** Then the license server is no longer used. Open the plugin's license
  window, "No internet on this computer?", then "Look for it online" (or download the file
  and use "Load switch-on file..."), then enter your license key.
- **Not here?** Then the license server works and nothing needs to be done.
- The file is signed. The plugin checks the signature, so it does not matter where you got the
  file from; anyone may pass it on.
- It contains no names, no email addresses, no license numbers and no license keys: only
  one-way fingerprints of the keys that were valid on the last day the server worked. A
  fingerprint cannot be turned back into a key.
- The limit of two computers per license still applies, although the software cannot count
  them any more.

**Deutsch.** Die Plugins von Irrvogel Interactive prüfen Lizenzschlüssel über einen
Lizenzserver. Funktioniert dieser Server auf Dauer nicht mehr, kommt in dieses Repository die
Datei `irrvogel-switch-on.json`. Damit lässt sich jedes Irrvogel-Plugin mit dem eigenen
Lizenzschlüssel ohne Lizenzserver aktivieren, offline und in jeder Version (Lizenzbedingungen
Abschnitt 1, AGB Abschnitt 3).

- **Liegt die Datei hier?** Dann wird der Lizenzserver nicht mehr verwendet. Im Plugin das
  Lizenzfenster öffnen, "No internet on this computer?", dann "Look for it online" (oder die
  Datei herunterladen und "Load switch-on file..." wählen), dann den Lizenzschlüssel eingeben.
- **Liegt sie nicht hier?** Dann funktioniert der Lizenzserver, und es ist nichts zu tun.
- Die Datei ist signiert. Das Plugin prüft die Signatur, daher ist egal, woher die Datei
  kommt; jeder darf sie weitergeben.
- Sie enthält keine Namen, keine E-Mail-Adressen, keine Lizenznummern und keine
  Lizenzschlüssel, nur Einweg-Fingerabdrücke der Schlüssel, die am letzten Tag gültig waren, an
  dem der Server funktioniert hat. Ein Fingerabdruck lässt sich nicht in einen Schlüssel
  zurückrechnen.
- Die Grenze von zwei Computern je Lizenz gilt weiter, auch wenn die Software sie nicht mehr
  zählen kann.
