# Irrvogel switch-on file / Irrvogel-Einschaltdatei

**English.** If Irrvogel's license server ever stops working for good, the file `irrvogel-switch-on.json` appears here. With it, every Irrvogel plugin activates offline with your own license key.

- **File here?** In the plugin's license window choose "No internet on this computer?", then "Look for it online", and enter your license key.
- **Not here?** The license server works. Nothing to do.

**Deutsch.** Falls der Lizenzserver von Irrvogel einmal dauerhaft ausfällt, erscheint hier die Datei `irrvogel-switch-on.json`. Damit lässt sich jedes Irrvogel-Plugin offline mit dem eigenen Lizenzschlüssel aktivieren.

- **Datei hier?** Im Lizenzfenster des Plugins "No internet on this computer?" wählen, dann "Look for it online", dann den Lizenzschlüssel eingeben.
- **Nicht hier?** Der Lizenzserver funktioniert. Es ist nichts zu tun.
